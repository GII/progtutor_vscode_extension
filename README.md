# ProgTutor VSCode extension

VSCode extension to use with the ProgTutor simulator.

## Usage requirements

- VSCode.
- VSCode Extensions:
  - Python.
  - Python Environments.
- VSCode -> Preferences -> Settings -> Extensions:
  - Python: Mark "Use Environments Extension".
  - Python Environments: set "Auto Activation Type" to "shellStartup".

## Installation

- Download the latest *.vsix release: <https://github.com/GII/progtutor_vscode_extension/releases>
- Install on VSCode:
  - VSCode -> Extensions -> ... -> Install from VSIX:
    - Select progtutor-*.vsix
